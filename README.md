# Ahn Research Group

Research site of Chang-Han Ahn (Department of Secondary Battery Systems, Korea Polytechnics, Daegu Campus).

The site describes how AI is assessed and verified for energy and manufacturing tasks: the MAIA task allocation check, research areas, publications, development activity and open data.

- Pages are static HTML (1280×720 canvas, Korean and English).
- `pulse.js` holds aggregate development counts produced by `tools/build_pulse.py`; no session text is published.
- `tools/copy_lint.py` checks the site copy before publication.

Data and code used in the papers are deposited on Zenodo:
